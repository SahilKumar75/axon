# Axon — Workflow

Same policy as PROBE: note-taking is part of the work.

## Update notes whenever:

- a roadmap or definition decision is made
- a tracer component is added or changed
- an experiment is run
- a collapse / failure pattern is observed
- a stage produces evidence
- the contribution is narrowed or a sub-idea is dropped

## Each session captures:

session number, date, phase, current goal, key decisions, what was tried, what failed,
what changed, and what the next session should do.

## File map

- README.md ............ project overview and pitch
- notes/IDEA_NOTES.md .. raw thinking, metaphors, definitions
- notes/ROADMAP.md ..... staged campaign plan
- notes/RESEARCH_LOG.md  running session record
- notes/RELATED_WORK.md  literature survey + where Axon is still novel
- notes/OPEN_QUESTIONS.md decisions that block progress
- notes/EVALUATION.md ... how we prove the claims (the detection contest)
- notes/FUTURE_DIRECTIONS.md the 5 novel directions + recommended lead
- notes/TIMELINE.md ..... the plan of record, 7 stages with stop gates (follow this)
- notes/DEEP_RESEARCH_2026-07-21.md the literature sweep + the pivot
- notes/SESSION_TEMPLATE.md copy-paste template
